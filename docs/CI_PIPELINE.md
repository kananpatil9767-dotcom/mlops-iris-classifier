# CI Pipeline and Regression Testing

## 1. Introduction

Continuous Integration (CI) helps automatically check code changes whenever they are pushed to GitHub. It helps identify errors early and keeps the project reliable.

## 2. CI Pipeline

This project uses GitHub Actions to automate code verification and testing.

The CI workflow is stored in `.github/workflows/`.

## 3. Automated Testing

The pipeline runs automated tests to verify that the project components work as expected. These tests help detect regressions when code is changed.

## 4. Benefits

- Automatically checks code changes.
- Helps identify errors early.
- Improves code reliability.
- Helps prevent existing functionality from breaking.

## 5. Conclusion

The CI pipeline improves the reliability of the Iris Classifier project by automating code verification and regression testing through GitHub Actions.
